# GeekWiller — Mises à jour de Manga Caisse

Ce dépôt est l'espace officiel prévu pour publier les futures mises à jour du logiciel **Manga Caisse GeekWiller**.

## État actuel

- **v1.4** : version installée sur le PC de développement.
- **v1.5** : en préparation et en test. Son interface « Mises à jour » est une démonstration ; le téléchargement depuis GitHub n'est pas encore activé.
- **Aucune version téléchargeable n'est publiée dans les Releases de ce dépôt pour le moment.**

## Fonctionnement prévu

1. Une nouvelle version est développée et testée sur Windows.
2. Un installateur Windows 10/11 est vérifié et publié dans une **GitHub Release**, avec son numéro de version et son empreinte SHA-256.
3. GeekWiller vérifie ce dépôt en ligne pour savoir si une version plus récente est disponible.
4. L'utilisateur choisit quand télécharger et installer la mise à jour.
5. Le programme sauvegarde les données locales avant remplacement de l'application. En cas d'erreur, les données doivent rester intactes.

## Sécurité et confidentialité

- **Ne jamais publier** le catalogue, les stocks, l'historique des ventes, les sauvegardes, les jaquettes privées ni des informations personnelles dans ce dépôt public.
- Les données du PC personnel et du PC de la boutique restent **locales et indépendantes**.
- Une mise à jour ne doit pas s'installer automatiquement pendant une vente.
- Un téléchargement doit provenir d'une publication officielle de ce dépôt et être vérifié avant exécution.
- L'installation et la conservation des données devront être testées sur **Windows 10 et Windows 11** avant une utilisation en boutique.

## Important

Ce dépôt est en cours de mise en place. Il ne fournit actuellement **aucune mise à jour opérationnelle**. Les fonctions de caisse doivent aussi être évaluées pour leur conformité réglementaire avant toute utilisation commerciale réelle.
